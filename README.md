# IRFC Website

A Next.js 16 prototype for IRFC's U.S. fertility-care website. The experience combines IRFC's approved purple-and-gold identity with a patient-task-first information architecture, clear appointment paths, and reusable content templates.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Responsive homepage with patient journeys, treatment entry points, clinical trust, locations, resources, and consultation CTAs
- Accessible desktop and mobile navigation
- Reusable content-page template for top-level site sections
- Metadata, 404 handling, reduced-motion support, and mobile sticky appointment action
- IRFC logo assets and brand-aligned design tokens

## Content and launch notes

The website is a design and implementation prototype. Before production launch, IRFC should confirm physician and location data, appointment and portal destinations, claims and clinical statistics, contact details, photography rights, privacy language, and CRM form delivery.
